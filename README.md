# Yashraj Ghemud — Portfolio

A modern, animated, CSS-first portfolio site. No JS required for the core UI/animations; progressive enhancements are used where supported.

## Project structure
- `index.html` — Main site
- `style.css` — All styles and animations
- `app.js` — Optional progressive enhancements (not required for core)
- `portfolio_logo.png` — Team logo

## Features
- Sticky, interactive navbar with scroll progress
- Smooth, scroll-reactive section backgrounds
- Accessible reveal animations (no disappearing-on-scroll)
- Projects, Skills, Achievements, Contact sections
- CSS-only hover effects with masked sweeps and shines
- Dedicated Try Projects page (optional) if present

## Getting started
Just open `index.html` in your browser.

## Contributing
PRs welcome. Keep it lightweight and CSS-first. Prefer progressive enhancement and graceful fallbacks.
